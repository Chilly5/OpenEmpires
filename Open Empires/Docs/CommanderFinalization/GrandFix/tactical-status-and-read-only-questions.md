## Implemented source

- Early generic information framing precedes gameplay controls/preview replacement.
  It preserves existing explicit polite actions and syntax-only direct command forms.
  Reading syntax never creates a strategic intent/ID. Known strategic explanations
  remain on their established path; offline strategy status does not call a provider
  or cancel an in-flight interpretation.
- A dedicated information route creates no authority ticket, candidate, goal,
  reservation, command, strategy evaluation or approval. Provider executable outcomes
  cannot enter gameplay admission. Pending previews and active goals remain intact.
- Detached tactical observations group owned goals by their game-owned request and
  carry requested total/new counts, living owned and attributable produced outputs,
  general/attributable/native-pending queues, producer readiness, next-unit resource
  deficits where a real producer is available, population/queued capacity, dependency
  wait/failure, reservation/protection counts, takeover and target availability.
  Observation never calls planner.Plan or manager.Tick. Human-protection lookup has a
  dedicated non-mutating peek instead of expiring a lease during a question.
- The goal manager records the last planner observation tick. StatusReason remains
  current reported status (which can also come from cancellation); display therefore
  says “Reported status reason”, not falsely attributing all text to planning.
- Canonical aliases identify named unit/building subjects independently of active
  goals. No match returns no matching request, not the first unrelated goal. Matched
  steps are prioritized inside compound requests. Multiple relevant requests show
  bounded choices instead of inventing a singular reason.
- Tactical narration is generated from the fresh game-side snapshot after provider
  latency, not fabricated free-form model status. Available local observations remain
  usable on provider fault/timeout. Non-tactical information questions retain the
  bounded knowledge-answer route and never acquire gameplay authority.
- The tactical JSON subset is capped at1536 characters and marks omitted whole
  steps/requests explicitly; provider context remains8192 and question facts512.
  Runtime IDs/coordinates are not exported as target selectors; canonical content
  IDs remain allowed. If necessary the tactical subset replaces the general knowledge
  slice with an explicit omitted marker instead of raising the context bound.
