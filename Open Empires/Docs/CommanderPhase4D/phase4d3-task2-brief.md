## Objective

Create a truly detached, bounded `StrategicAdaptationProposal` and pure source-capture/builder/stale-checker. The proposal is a player-facing value, **never** execution authority. It may contain owner, source plan ID/creation tick/revision/status/milestone/blocker fingerprint, current/proposed objective, pending intent ID, typed old/proposed target copies, old canonical budget, separately labeled proposed feasibility quote, structured reason, bounded explanation, and `RequiresPlayerApproval=true`. It must not retain `StrategicPlan`, `StrategicPlanHealthSnapshot` (unless all its values are demonstrably detached and reviewer accepts it), `StrategicIntent`, `StrategicPlanner`, `GameSimulation`, Unity objects, commands, callbacks, or live collections.

## Source snapshot and builder

Capture source identity, owner-scoped fresh `StrategicPlanHealthSnapshot`, **actual plan milestone tactical requests** (not template constants), and canonical approved budget in one synchronous operation before any provider await. The caller may obtain the plan/health via the existing read-only planner API and pass them to a pure copier; the copier itself must not invoke planner methods. Recheck source plan identity/revision after copying; if inconsistent return no source. Include fitted worker allocation targets and exact structure/unit requests, with stable milestone/request ordering. Multiple active plan handling belongs to the host in Task 3; a pure source value represents exactly one plan.

Build the proposal from that detached source, a supported pending intent, and optional fresh detached `StrategicFeasibility` quote. If a proposed fixed target shape is needed, an ephemeral `StrategicPlanRegistry.CreateDefault().CreatePlan(intent)` is allowed strictly for copying its static template targets, with no submit/reservation/goal action. Do not add arbitrary executable target/budget parameters; current approval rejects them. Copy all lists into immutable scalar DTOs; validate lengths/enums/counts, deterministic order, bounded explanation, and explicit stable `ToJson` fields. The checker compares a proposal with a **fresh** owner-scoped source observation: exact plan ID/creation tick/revision/status/milestone plus the blocker assumption; terminal/replaced/paused/resumed/recovered cases fail closed. Checker has no power to submit or cancel.

Run focused Unity MCP EditMode RED then GREEN as the only Unity runner, saving exact discovered IDs/counts, job IDs, native XML/payload, hashes, zero compiler errors, and source SHA-256.
