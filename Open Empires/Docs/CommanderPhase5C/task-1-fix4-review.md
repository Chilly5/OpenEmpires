## New Important finding — Clarify graph can bypass the name gate

**Important (P1), `CommanderSemanticProvider.cs:165` and `CommanderRequestGraphDraft.cs:165-168`:** The wrapper returns an already valid **Clarify** unchanged. The strict parser explicitly accepts a provider Clarify containing `pending.nodes` and `missingSlots`, then builds an ordinary graph draft (`CommanderSemanticJson.cs:77-85`; `CommanderRequestGraphDraft.cs:80-123`). That graph's `Probe` validates each offered completion as a Request but never applies the original game's unresolved-name metadata (`CommanderRequestGraphDraft.cs:126-136`). On a local slot reply, `Resolve` returns that Request directly (`:154-168`). The UI deliberately skips a second provider request for local graph continuation (`CommanderChatUI.cs:463-479`), clears the pending graph on local Request (`CommanderChatUI.Clarification.cs:85-89`), and proceeds to ordinary admission (`CommanderChatUI.cs:534-535,627-630`). Thus there is no later call to `RequireNameConfirmation`.

Concrete source-valid path: for the original player text `Train three new longbowmna`, the game-owned resolver supplies the unresolved Longbowman hint (the direct-actionable fixture establishes that input's hint). A provider can respond with a strict Clarify whose pending Independent node is `EnsureUnitCount` with `unit: "Longbowman"`, `quantityMode: "New"`, and missing `count`, offering Count alternative `3`. The graph parser allows a missing `count`/Count slot (`CommanderRequestGraphDraft.cs:95-122,443-450`); a local `3` matches Count (`:404-415`), produces a parsed Request (`:126-136,165-168`), and enters ordinary admission. The player's `3` resolved only quantity; it was not explicit confirmation of `Longbowman`. A canonical-name, source-kind, or correction slot could yield the same class of bypass when another field is resolved. The worker-only count draft has no unit/structure/producer field (`CommanderPendingClarification.cs:11-45`), so this finding rests on the graph path, not an assumed worker-draft repro.

The HintGate cases supply Request, DynamicPlan, and Answer transport responses, but no provider Clarify graph with hinted canonical content followed by a local slot answer.
