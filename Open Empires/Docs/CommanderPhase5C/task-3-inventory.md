## Farm capacity and incumbent assignment

- `Assets/Scripts/AI/Commander/Economy/CommanderPlanner.Economy.cs`: `VisibleEconomyTargets` gives Farm nodes capacity 1; `TryResolveWorkerAssignments` counts incumbents in `used`, then assigns within that capacity. However, its incumbent scan skips every worker in the current `selected` set. `PlanWorkerAllocation` selects eligible workers before assignment, sorting idle workers first (`WorkerPriority`), while an existing eligible villager already assigned to a Farm can be in that selection for a reassignment request. Excluding that selected incumbent can make the same Farm appear free and overbook it. Ensure capacity is based on actual non-dead/non-departed occupants, including selected incumbents that remain assigned there; explicitly account for incumbent retention before preferring an idle worker.
- Reuse `MatchesDestination`, `LegalFarm`, `VisibleEconomyTargets`, and `TryResolveWorkerAssignments`; preserve selected IDs, ownership, human-protection/reservation checks, and all-or-nothing preflight. Do not count destroyed/foreign/incomplete Farms as usable.

Add the occupied-Farm selected-incumbent plus idle-worker case here; `Assets/Tests/EditMode/CommanderPhase5BResourcePlacementFixTests.cs` is construction/Farm-source coverage, not allocation capacity coverage.

## Death/missing versus human takeover

- `CommanderPlanner.cs`, `ObserveCapability`: counts only currently living owned unprotected subjects. When `eligible == 0`, it unconditionally says the player took control of every eligible unit. If captured subjects are missing, dead, or transferred, this incorrectly attributes that outcome to human control. Distinguish `workerAuthority.IsHumanProtected` from missing/dead/foreign facts; report loss separately, and never silently replace an exact subject.
- Existing test `Assets/Tests/EditMode/CommanderPhase4GCapabilityTests.cs`, `CapabilityGoal_HumanOverrideBlocksWithoutFalseCompletion`, verifies true human takeover. The top-level `Plan` frozen-worker guard distinguishes missing/dead/foreign request-bound villagers, but capability observation lacks matching regression coverage. Add parameterized disappeared/dead/transferred versus protected-unit cases against the issued command's exact IDs.
